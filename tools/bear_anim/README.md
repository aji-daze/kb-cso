# しろくまの動く絵

`docs/read/art/bear.webp`（ホーム画面で動いているやつ）を作るスクリプト。

元絵（`bear-source.png`）は**一切描き直していない**。
その上に、めくれる紙とまぶたをプログラムで重ねているだけ。
だからしろくま本体は動かない。動くのはページと目だけ。

## 作り直す

```sh
pip install pillow numpy
python3 tools/bear_anim/build.py          # docs/read/art/ に書き出す
python3 tools/bear_anim/build.py /tmp     # 場所を指定するとき
```

`bear.webp`（480px・背景透過・アニメーション）と
`bear-reading.gif`（400px・白背景）が出る。
アプリが使うのは webp のほうだけ。gif は人に渡すとき用。

## 中身

| ファイル | 役目 |
| --- | --- |
| `page.py` | 本の形（折り目の位置、表紙の外端）と、紙のめくれ方 |
| `blink.py` | 目の位置と、まぶたの降り方 |
| `build.py` | コマを並べて書き出す |

座標はすべて `bear-source.png`（1254×1254）の原寸。
元絵を差し替えるなら、`page.py` の `A`/`B`/`V*` と `blink.py` の `EYES` を測り直す。

### 紙のめくれ方（page.py）

折り目（`A`–`B`）を軸に紙を回す。角度 0 で右の見開きに寝て、π で左に寝る。
`BEND` は紙の反り。0 だと板に見えるので 1.25 入れてある。
先に行くほど角度が進むので、紙が丸まって見える。

本の稜線（`TOP_EDGE`）より下は `above_mask` で隠す。
表紙の裏側が見えている絵なので、寝ている紙は本の中に隠れるのが正しい。

毛の上に紙が出ると白同士で見えなくなるため、元絵と同じ青灰色の細い線と
やわらかい落ち影をつけてある。紙が真横を向いて細く見えるコマでは、
線を弱める（そうしないと鼻から棒が出ているように見える）。

### まばたき（blink.py）

目の楕円をまわりの毛の色で上から塗りつぶし、まぶたの線を1本引く。
毛の色は目のまわりから拾う（眼鏡の青みと目の暗さは外して中央値）。
線は目の高さの 30% のところで止まる。真下まで降ろすと閉じた目に見えない。
