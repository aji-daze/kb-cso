# MEMO — 開いた瞬間に書けるメモ

公開先: `https://aji-daze.github.io/kb-cso/memo/`

開くと空の入力欄にカーソルが立っている。そのまま書けば自動で保存される。

## 見た目

- 白黒2階調だけ。枠線・角丸・塗り・アクセント色なし。OS のライト/ダークに従う
- 書いている間は上のバーが消えて文字だけになる。手が1.5秒止まるか、マウスを動かすと戻る
- 本文は最大660px幅で中央に置く（1行が長くなりすぎない）
- スマホではキーボードの真上に補助バー（下線・コード・字下げ・完了）が出る
- 一覧は全画面。題名と日付だけを余白で区切って並べる

## 速さのための作り

| やったこと | 理由 |
| --- | --- |
| HTML 1枚に CSS と JS を直書き（約28KB、外部読み込みゼロ） | 往復は1回だけ。描画を止めるファイルがない |
| フォント・ライブラリを使わない（system-ui） | ダウンロードも解析も発生しない |
| メモは1件ずつ別キー `memo:<id>` で localStorage に保存 | 起動時に全件を読まない。保存も書いた1件分だけ |
| 一覧は開いたときに初めて組み立てる | 起動時の仕事を「入力欄にフォーカス」だけにする |
| Service Worker でキャッシュ優先 | 2回目以降はネットワークを待たない。電波なしでも開く |
| Service Worker の登録は読み込み完了の1秒後 | 初回の起動を邪魔しない |

手元の計測（Chromium、ローカル配信）: DOMContentLoaded 初回 約80ms / 2回目（キャッシュ）約20ms。

## 使い方

| 操作 | 内容 |
| --- | --- |
| ≡ / `Ctrl`(`⌘`)+`K` | 一覧と検索。検索欄で `Enter` を押すと先頭のメモを開く |
| ＋ / `Alt`+`N` | 新しいメモ |
| ⇪ | スマホは共有シート、PC はクリップボードへコピー |
| × | このメモを削除（5秒間「元に戻す」が出る） |
| `Ctrl`(`⌘`)+`S` | その場で保存（普段は入力の0.25秒後と、画面を離れた瞬間に自動保存） |
| U̲ / `Ctrl`(`⌘`)+`U` | 選んだ文字に下線。もう一度押すと外す |
| ‹› / `Alt`+`C` | コードブロックを入れる（選んだ文字があればそれを包む） |
| `Tab` | 字下げを入れる |

- 中身を全部消したメモは自動で消える（空メモは残らない）
- 一覧は更新が新しい順。1行目が題名になる
- 別タブで同じメモを書き換えた場合、こちらが未編集なら追従する

## 書式

保存は素のテキストのまま。書き出した `.md` は GitHub などでもそのまま表示できる。

| 書式 | 書き方 | 画面での見え方 |
| --- | --- | --- |
| 下線 | `<u>文字</u>` | 文字に下線。`<u>` `</u>` は薄く残る |
| コードブロック | 行頭に ```` ``` ````（後ろに言語名も可）と打って改行 | 等幅・薄い地の枠。右上に「コピー」 |

コードブロックの中:

- 改行すると前の行の字下げを引き継ぐ
- 最後の行で ```` ``` ```` と打って改行すると外に出る。↓ / → でも出られる
- 中身を空にして Backspace でブロックごと消える
- ```` ``` ```` を含む文章を貼り付けると、その場でコードブロックに変わる

下線の記号を隠さないのは、隠すと文字の位置がずれて入力欄が壊れるため
（透明な入力欄の下に同じ文字を描いて飾る作りで、日本語入力と元に戻すをそのまま使えるようにしている）。

## 保存について

データはまずこの端末のブラウザ（localStorage）に入る。Google ドライブ同期を設定しなければ、どこにも送らない。
一覧下部の「書き出し」で JSON を保存し、別端末で「読み込み」しても移せる。
読み込みは同じ ID のメモがあれば更新日時が新しい方を残す。`.txt` / `.md` は1件のメモとして取り込む。

localStorage の容量は多くのブラウザで約5MB（日本語でおよそ250万字）。

## Google ドライブ同期

一覧下部の「同期」から設定する。メモは「マイドライブ / MEMO」に1件1ファイルの `.md` で置かれ、
同じ設定をした端末どうしで揃う。

```
書く → 端末に即保存 → 送信待ち（memo.q）に ID を残す
     → オンラインでログイン中なら、手が3秒止まったらドライブへ送る
オフライン → 送信待ちにたまる（バーに「オフライン · 未送信3」）
つながる → たまった分をまとめて送り、ドライブ側の変更も取り込む
```

| 場面 | 動き |
| --- | --- |
| いつ同期するか | 書いて3秒後 / 起動時 / オンラインに戻ったとき / 画面に戻ったとき（20秒以上空いていれば）/ 開いている間は1分ごと |
| 別の端末で同じメモを同時に書き換えた | 両方残す。ドライブ側の版は先頭に「（競合: 別の端末の版）」を付けた別のメモになる |
| メモを消した | ドライブではゴミ箱に移すだけ（30日は戻せる） |
| ドライブで .md をゴミ箱に入れた | 端末からも消える（端末で書き換え中なら、作り直して送る） |
| ログインが切れた（1時間） | バーに「再ログイン」。押すと Google の画面へ移って戻る。切れている間も書けて、変更はたまる |
| 同期をやめる | 端末のメモもドライブのファイルも残る |

権限は `drive.file`（このアプリが作ったファイルだけ読み書きできる）。ドライブの他のファイルは見えない。
そのため、ドライブ上で自分で作った .md を MEMO フォルダに入れても取り込まれない。

### 準備（Google Cloud、最初に1回）

read / music のドライブ連携で使っている OAuth クライアント ID を流用できる（設定画面に自動で入る）。
その ID の設定で次を済ませる。

1. 「承認済みのリダイレクト URI」に `https://aji-daze.github.io/kb-cso/memo/` を追加
2. 「承認済みの JavaScript 生成元」に `https://aji-daze.github.io` があること
3. OAuth 同意画面の「データアクセス」に `https://www.googleapis.com/auth/drive.file` を追加
4. 公開ステータスを「本番環境」にする（「テスト」のままだと7日ごとに承認し直しになる。drive.file は審査不要）

### 限界

- サーバーを持たないので、Google の許可は1時間で切れ、裏で自動更新できない。切れたら1回タップが要る
- ログインは画面ごと Google へ移る方式（ポップアップはホーム画面の iPhone アプリで戻らないことがあるため）。
  iPhone のホーム画面アプリでの動作は実機で確かめること
- ドライブ上でファイルの中身を直接書き換えた場合も取り込まれる（版が変わるため）

## OS との連携（ホーム画面に追加・インストールしたとき）

| 機能 | 対応 | 内容 |
| --- | --- | --- |
| 共有メニュー | Android（Chrome） | 他のアプリの「共有」から MEMO を選ぶと、その文字・URL が新しいメモになる |
| アイコン長押し | Android / PC（Chrome, Edge） | 「新しいメモ」「メモの一覧」 |
| ファイルを開く | PC（Chrome, Edge） | `.txt` / `.md` を「MEMO で開く」と1件ずつメモとして取り込む |
| 二重起動しない | Chrome, Edge | 共有やショートカットで開いても、開いている窓を使い回す |
| 保存領域の保護 | Chrome, Safari | 最初の保存時に、容量整理でメモを消さないようブラウザに頼む |
| キーボード | iPhone / iPad | 入力欄に触れても拡大しない。キーボードの分だけ画面を縮めて本文を隠さない |

Safari（iPhone/iPad）は共有メニュー・ファイルを開く・アイコン長押しに対応していない（Web アプリに許されていない）。

## ホーム画面に追加する

- iPhone/iPad: Safari で開く → 共有 → 「ホーム画面に追加」
- Android: Chrome で開く → メニュー → 「ホーム画面に追加」 / 「アプリをインストール」

## ファイル

```
memo/
  index.html   画面・見た目・動作のすべて
  sync.js      Google ドライブ同期（設定したときだけ、起動後に読む）
  sw.js        オフライン用キャッシュ
  manifest.json
  icons/
```

`index.html` を更新したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が1回残る。
