# MEMO — 開いた瞬間に書けるメモ

公開先: `https://<ユーザー名>.github.io/kb-cso/memo/`

開くと空の入力欄にカーソルが立っている。そのまま書けば自動で保存される。

## 見た目

- 白黒2階調だけ。枠線・角丸・塗り・アクセント色なし。OS のライト/ダークに従う
- 書いている間は上のバーが消えて文字だけになる。手が1.5秒止まるか、マウスを動かすと戻る
- 本文は最大660px幅で中央に置く（1行が長くなりすぎない）
- 一覧は全画面。題名と日付だけを余白で区切って並べる

## 速さのための作り

| やったこと | 理由 |
| --- | --- |
| HTML 1枚に CSS と JS を直書き（約12KB、外部読み込みゼロ） | 往復は1回だけ。描画を止めるファイルがない |
| フォント・ライブラリを使わない（system-ui） | ダウンロードも解析も発生しない |
| メモは1件ずつ別キー `memo:<id>` で localStorage に保存 | 起動時に全件を読まない。保存も書いた1件分だけ |
| 一覧は開いたときに初めて組み立てる | 起動時の仕事を「入力欄にフォーカス」だけにする |
| Service Worker でキャッシュ優先 | 2回目以降はネットワークを待たない。電波なしでも開く |
| Service Worker の登録は読み込み完了の1秒後 | 初回の起動を邪魔しない |

手元の計測（Chromium、ローカル配信）: DOMContentLoaded 初回 約80ms / 2回目（キャッシュ）約20ms。

## 使い方

| 操作 | 内容 |
| --- | --- |
| ≡ / `Ctrl`(`⌘`)+`K` | 一覧と検索。検索欄で `Enter` を押すと先頭のメモを開く |
| ＋ / `Alt`+`N` | 新しいメモ |
| ⇪ | スマホは共有シート、PC はクリップボードへコピー |
| × | このメモを削除（5秒間「元に戻す」が出る） |
| `Ctrl`(`⌘`)+`S` | その場で保存（普段は入力の0.25秒後と、画面を離れた瞬間に自動保存） |
| `Tab` | 字下げを入れる |

- 中身を全部消したメモは自動で消える（空メモは残らない）
- 一覧は更新が新しい順。1行目が題名になる
- 別タブで同じメモを書き換えた場合、こちらが未編集なら追従する

## 保存について

データはこの端末のブラウザ（localStorage）にだけ入る。サーバーには何も送らない。
端末間の同期はない。一覧下部の「書き出し」で JSON を保存し、別端末で「読み込み」すれば移せる。
読み込みは同じ ID のメモがあれば更新日時が新しい方を残す。`.txt` / `.md` は1件のメモとして取り込む。

localStorage の容量は多くのブラウザで約5MB（日本語でおよそ250万字）。

## ホーム画面に追加する

- iPhone/iPad: Safari で開く → 共有 → 「ホーム画面に追加」
- Android: Chrome で開く → メニュー → 「ホーム画面に追加」 / 「アプリをインストール」

## ファイル

```
memo/
  index.html   画面・見た目・動作のすべて
  sw.js        オフライン用キャッシュ
  manifest.json
  icons/
```

`index.html` を更新したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が1回残る。
