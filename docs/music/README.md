# ミュージック（自分用の音楽プレーヤー PWA）

端末（microSD 含む）や Google ドライブの音楽ファイルを取り込んで、**オフラインで**聴くための
個人用プレーヤーです。インストール不要の PWA なので、ブラウザで開いてホーム画面に追加するだけで使えます。

公開先: `https://aji-daze.github.io/kb-cso/music/`

---

## 1. スマホに入れる

1. Chrome（Android）または Safari（iPhone）で上の URL を開く
2. アプリの 設定（右上の歯車）→ **ホーム画面に追加** をタップ
   - Android: そのまま追加ダイアログが出ます（出ない場合は Chrome のメニュー ⋮ →
     「アプリをインストール」／「ホーム画面に追加」）
   - iPhone: 共有ボタン（□に↑）→ **ホーム画面に追加**
3. 追加されたアイコンから起動する（アドレスバーのない全画面で開きます）

一度開いておけば、以後は**電波がなくても起動**します（アプリ本体は端末にキャッシュされます）。

### 「インストール」が出てこないとき

- **アプリ内ブラウザで開いている**（LINE や X のリンクから飛んだ場合など）… メニューから
  「ブラウザで開く」を選び、Chrome / Safari で開き直してください。
- **iPhone で Chrome アプリを使っている** … iOS はホーム画面への追加が **Safari 限定**です。
- **一度開いただけ** … Service Worker の登録が終わる前だと条件を満たしません。
  ページを一度再読み込みしてから、もう一度お試しください。
- 設定画面の「ホーム画面に追加」には、オフライン用の準備が終わっているかも表示されます。

---

## 2. 曲を入れる

右上の歯車 → **曲を取り込む** から。

### 端末・microSD から（いちばん簡単・設定不要）

- **端末・microSD から選ぶ** … ファイル選択画面が開くので、曲を選ぶ（複数選択可）。
  microSD の中も、端末のファイル選択画面から辿れば選べます。
- **フォルダごと取り込む** … PC やフォルダ選択に対応した端末向け。Android では使えないことがあるので、
  その場合は上の「ファイルを選ぶ」で全選択してください。

取り込むと **ファイルの中身をアプリ内（IndexedDB）にコピー**します。
元のファイルを消したり SD を抜いたりしても再生できます。逆に、容量はその分消費します。

対応形式は端末のブラウザが再生できるもの（mp3 / m4a / aac / flac / wav / ogg など）。
タグ（曲名・アーティスト・アルバム・ジャケット）は ID3v2 / ID3v1 / MP4 / FLAC から読み取ります。
タグがない場合は `07 - アーティスト - 曲名.mp3` のようなファイル名から推測します。

### Google ドライブから

初回だけ、自分の Google アカウントで OAuth クライアント ID を作る必要があります（→ 次の章）。
設定後は、設定 → **Google ドライブから取り込む** でフォルダを辿り、

- フォルダを開いて **このフォルダを取り込む**（サブフォルダも含めて全部）
- または曲を個別にタップ

でダウンロードされ、端末に保存されます。**取り込んだ後はオフラインで聴けます**（ストリーミングではありません）。

## 3. Google ドライブの設定（任意・1回だけ）

ドライブを使わないならこの章は飛ばして構いません。

1. [Google Cloud Console](https://console.cloud.google.com/) を開き、プロジェクトを新規作成（名前は何でも可）
2. **API とサービス → ライブラリ** で「Google Drive API」を検索して **有効にする**
3. **API とサービス → OAuth 同意画面**
   - User Type: **外部**
   - アプリ名・サポートメール・デベロッパー連絡先を自分のものにして保存
   - スコープは追加しなくて構いません（アプリ側から要求します）
   - **テストユーザー** に自分の Gmail アドレスを追加
   - 公開ステータスは「テスト」のままで OK（自分だけが使うので審査は不要です）
4. **API とサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
   - アプリケーションの種類: **ウェブアプリケーション**
   - **承認済みの JavaScript 生成元** に以下を追加
     ```
     https://aji-daze.github.io
     ```
     （末尾のパスは付けません。ローカルで試すなら `http://localhost:8899` も追加）
   - リダイレクト URI は不要です
5. 表示された **クライアント ID**（`....apps.googleusercontent.com`）をコピー
6. アプリの 設定 → Google ドライブから取り込む → 入力欄に貼って **接続する**

クライアント ID は端末内にだけ保存されます（このリポジトリには入りません）。
アクセス権は **読み取り専用**（`drive.readonly`）で、ドライブ側のファイルは一切変更しません。

> 「このアプリは Google で確認されていません」と出たら、**詳細 → (アプリ名) に移動** で進めます。
> 自分がテストユーザーに入っていれば使えます。テストモードのトークンは期限が短いので、
> しばらく経つと再ログインを求められることがあります（取り込み済みの曲には影響しません）。

## 4. 使い方

| 場所 | できること |
| --- | --- |
| 曲 / アルバム / アーティスト | 一覧、すべて再生、シャッフル再生 |
| プレイリスト | お気に入り・最近追加・最近再生・よく聴く（自動）＋自分で作るプレイリスト |
| 曲の右の「⋮」 | 次に再生 / キューに追加 / プレイリストに追加 / お気に入り / 曲の情報 / 削除 |
| ミニプレーヤー | タップで再生中画面へ |
| 再生中画面 | 速度・イコライザ・お気に入り・プレイリスト追加・スリープタイマー・音量 |
| 右上の 🔍 | 曲名 / アーティスト / アルバムをまとめて検索 |

- **ロック画面・通知領域**から再生／停止／曲送りができます（Media Session）。
- **スリープタイマー** … 5〜90分、または「この曲の終わりで停止」。時間指定のときは最後に音量がフェードします。
- **イヤホンが外れたとき** … 既定で停止。設定で「消音」「何もしない」に変更できます。
  （Android は端末側でも自動停止することが多いです）
- **再生速度** … 0.5〜2.0倍。音程は保たれます。
- **イコライザ** … 5バンド（60Hz / 230Hz / 910Hz / 3.6kHz / 14kHz）＋プリセット。
  オンにすると Web Audio を経由するので、**こだわりがなければオフのままが安定**します。
- アプリを閉じても、**最後に聴いていた曲と再生位置**を覚えています。

### ジャケット

- ファイルのタグに画像があればそれを使います。
- なければ iTunes の検索からアルバム名で自動取得します（設定でオフ可）。
- アルバム画面の **ジャケット** ボタンで、検索語を変えて手動で選び直せます。
  取得した画像も端末に保存するので、以後はオフラインで表示されます。

## 5. 気をつけること

- **容量**: 曲は端末のブラウザ保存領域に入ります。設定画面で使用量が見られます。
  設定の **保存を固定する** を有効にしておくと、空き容量が減っても勝手に消されにくくなります（推奨）。
- **iPhone**: ホーム画面に追加した状態で使ってください。Safari のタブのままだと
  バックグラウンド再生や保存の扱いが不安定です。
- ブラウザの「サイトデータを削除」を実行すると**曲も全部消えます**。
- 元の音楽ファイルはバックアップとして残しておくのが安心です（このアプリからは書き出せません）。

## 6. 中身（開発メモ）

ビルド不要の素の ES モジュール。GitHub Pages にそのまま置いてあります。

```
docs/music/
├── index.html      画面の骨組みとアイコン
├── style.css       ダークのミニマル配色
├── manifest.json   PWA の設定
├── sw.js           アプリ本体のキャッシュ（曲は扱わない）
└── js/
    ├── app.js      画面制御・取り込み・プレイリスト・設定
    ├── db.js       IndexedDB（tracks / blobs / art / playlists / settings）
    ├── tags.js     ID3v2・ID3v1・MP4・FLAC のタグ読み取り
    ├── player.js   再生・イコライザ・スリープタイマー・イヤホン検知
    ├── drive.js    Google ドライブ（読み取り専用）
    └── art.js      ジャケット検索（iTunes Search API / JSONP）
```

保存先の内訳:

| ストア | 中身 |
| --- | --- |
| `tracks` | 曲のメタ情報（曲名・アーティスト・長さ・再生回数など） |
| `blobs` | 音声ファイルの実体（キーは曲 ID） |
| `art` | ジャケット画像（キーはアルバム単位） |
| `playlists` | 自分で作ったプレイリスト |
| `settings` | 設定と最後の再生状態 |

アプリを更新したら `sw.js` の `VERSION` を上げると、端末側のキャッシュが入れ替わります。
