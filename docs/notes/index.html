つなぎ方

この PC（Chrome／Edge）なら、C:\Users\A.H\OneDrive\Obsidian を直接開けます。 Microsoft のサインインもアプリ登録も要りません（pomenote と同じ方式）。OneDrive フォルダそのものを選んでも、中の Obsidian を使います。 スマホ・タブレットは OneDrive につなぐ方で使います。

GitHub につなぐ（pomenote と同じ）

pomenote（ポメラタブ）と同じ非公開リポジトリを読み書きする。PC の同期（pomera_sync）が OneDrive の Obsidian とそろえるので、 ここで書いたものは PC の Obsidian にも届く。スマホ・タブレット向け。トークンは pomenote で使っているものをそのまま使える （fine-grained、pomera-data の Contents: Read and write）。トークンはこの端末の中でパスワードで暗号化して置く。

トークンを新しく作る ときは、Repository access を「Only select repositories → pomera-data」、Permissions の Contents を「Read and write」にする。

1. Microsoft アカウント

初回だけ：アプリの登録手順
  1. Microsoft Entra 管理センター → アプリの登録 → 新規登録
  2. サポートされるアカウントの種類は「任意の組織ディレクトリ内のアカウントと個人用 Microsoft アカウント」
  3. リダイレクト URI は「シングルページ アプリケーション (SPA)」を選び、

    を入れる（末尾の / まで一致させる）
  4. 概要ページのアプリケーション (クライアント) ID を下に貼る

栞で登録済みのアプリがあれば、それのリダイレクト URI に上の URL を追加するだけでよい。

2. 保管庫のフォルダ

PC のエクスプローラーでコピーしたパス（C:\Users\…\OneDrive\…）をそのまま貼ってもよい。「/」は OneDrive の一番上。
