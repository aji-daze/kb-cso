# ノート — OneDrive の Obsidian 保管庫を、どの端末からでも読み書きする

保存先は OneDrive のまま。PC では今まで通り Obsidian で使い、スマホや別の PC ではこの画面で読み書きする。
ブラウザで開き、ホーム画面に追加するとアプリとして起動する。

公開先: `https://<ユーザー名>.github.io/kb-cso/notes/`

## 仕組み（なぜ OneDrive の同期より安定するか）

この画面は**同期をしない**。開くたびに OneDrive 上のファイルを Microsoft Graph で直接読み、保存するたびに直接書く。
端末ごとに複製を持たないので、同期の食い違いや「競合コピー」の大量発生が原理的に起きにくい。

保存するときは、読んだときの版（eTag）を添える（`If-Match`）。その間に PC の Obsidian などが
同じノートを書き換えていれば OneDrive が断ってくるので、黙って上書きすることはない。そのときは

- 両方残す（自分の版を「ノート名 (競合 日時).md」として保存）
- OneDrive の版にする（自分の変更は捨てる）
- 自分の版で上書きする

から選ぶ。

`.obsidian/` など `.` で始まるフォルダには一切触らない（PC 側の Obsidian の設定を壊さないため）。

## できること

| | |
| --- | --- |
| 読む | 見出し・表・コード・画像・`[[リンク]]`・`[[ノート\|別名]]`・`[[ノート#見出し]]`・`![[画像.png\|300]]`・`![[ノート]]`（埋め込み）・`==強調==`・`#タグ`・`%%コメント%%`・`> [!note]` コールアウト・プロパティ（先頭の `---`） |
| 見え方 | **Aa** で文字の大きさ・行間・書体（ゴシック／明朝）・本文の幅・配色（自動／白／セピア／黒）。端末ごとに覚える（スマホは小さめ、PC は広め、のように分けられる） |
| 目次 | **☷** で見出しの一覧とマーカーの一覧。押すとそこへ飛ぶ。幅の広い画面では右に出したままにできる |
| マーカー | 閲覧中に文字を選ぶと色（黄・緑・青・桃・紫）が出る。引いたマーカーを押すと色を変える・外す |
| 書く | **編集** で書く画面に。見出しは大きく、マーカーは色付きのまま書ける（記号はカーソルを入れたときだけ出る）。道具帯で 本文／H1／H2／H3・太字・マーカー・箇条書き・番号・チェック・引用・リンク・区切り線・元に戻す。スマホとタブレットでは道具帯がキーボードのすぐ上に出る |
| 保存 | 2 秒止まると自動で OneDrive へ送る。チェックボックスは閲覧画面のまま押せる |
| 作る | ＋ から新しいノート。まだ無いノートへのリンクを押すと、その名前で作れる |
| 探す | 名前はその場で絞り込み。Enter で本文も探す（端末の控え＋ OneDrive の検索） |
| 電波がない | 一度開いたノートは読める。書いたものは端末に残り、電波が戻ったら送る |

マーカーの保存形式は Obsidian でそのまま色が付く形にしてある：

- 黄 → `==文字==`（Obsidian の標準）
- 他の色 → `<mark style="background: #BBFABBA6;">文字</mark>`（Highlightr プラグインと同じ形）

閲覧画面で引けないのは、太字やリンクをまたぐ範囲と、段落をまたぐ範囲。そのときは編集画面で引く。

やらないこと：名前の変更・移動・削除（リンクの張り替えが要るので PC の Obsidian でやる）、
Obsidian のプラグイン（Dataview など）の表示、グラフ表示。

## 非公開の仕組み（パスワード）

ノートの中身は GitHub には一切置かない。守りは3段になっている。

| どこ | 何で守るか |
| --- | --- |
| OneDrive 上のノート | Microsoft アカウントのサインイン。この画面の URL を他人が開いても、その人自身の OneDrive しか見えない |
| 端末に控えたもの（本文・書きかけ・ノート名・サインイン情報） | **パスワード**で暗号化（AES-GCM、鍵は PBKDF2 31 万回で作る）。ノート名も伏せてある。パスワードそのものは保存しない |
| 画面 | 開くたびにパスワードを聞く。画面を離れて一定時間（既定 5 分）経つと鍵がかかる |

- 初めて開いたときにパスワードを決める（6 文字以上）。端末ごとに決める（PC とスマホで同じにしてもよい）。
- Android の Google パスワード マネージャーに覚えさせられる。
- 自分専用の端末なら、設定の「この端末では入力を省く」で毎回の入力を省ける（そのぶん端末を拾われたら読める）。
- パスワードを忘れたら、鍵の画面の「パスワードを忘れた」で端末の控えを消してやり直す。OneDrive のファイルは消えない。

画面のプログラム（この `docs/notes/`）は GitHub Pages で公開されるが、中身は入っていないので見られても困らない。
クライアント ID も秘密ではない（それだけでは誰の OneDrive にも入れない）。

## 初回の準備

1. **アプリの登録**（Microsoft 側。1 回だけ）
   1. [Microsoft Entra 管理センター → アプリの登録](https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) → 新規登録
   2. サポートされるアカウントの種類：**任意の組織ディレクトリ内のアカウントと個人用 Microsoft アカウント**
   3. リダイレクト URI：**シングルページ アプリケーション (SPA)** を選び、`https://<ユーザー名>.github.io/kb-cso/notes/` を入れる（末尾の `/` まで一致させる）
   4. 概要ページの「アプリケーション (クライアント) ID」を控える

   栞（`../read/`）の OneDrive 取り込みで登録済みなら、そのアプリの「認証」→ SPA のリダイレクト URI に上の URL を足すだけでよい。
   「SPA」以外（Web など）で登録すると、ブラウザからトークンを取れずに失敗する。

2. **クライアント ID を入れる**：`config.js` の `CLIENT_ID` に書いておけば全端末で入力不要。
   書かなければ、各端末の ⚙ 設定で入れる（秘密の値ではないので公開してよい）。

3. ⚙ 設定 → **サインイン**。保管庫は `config.js` の `VAULT`（いまは `C:\Users\A.H\OneDrive` ＝ OneDrive の一番上）から
   **自動で探してつなぐ**（`.obsidian` があるフォルダ）。1 つならそのままつながり、複数あれば選ぶ画面が出る。
   手で選ぶときは **OneDrive から選ぶ**。PC のエクスプローラーでコピーしたパス（`C:\Users\A.H\OneDrive\…`）を貼ってもよい
   （「ドキュメント」などの日本語表示は OneDrive 上の本当の名前 `Documents` に読み替える）。

4. 電波のない所でも読みたければ、設定の **全ノートを端末に保存**。2 回目からは変わったノートだけ取り直す。

## 注意

- Microsoft の仕様で、ブラウザ用のサインインは **24 時間で切れる**。切れると上に帯が出るので、
  「サインイン」を押す。Microsoft 側にログインが残っていれば、そのまま戻ってくる。書きかけは端末に残っている。
- PC の OneDrive は、保管庫のフォルダを右クリック →「**常にこのデバイス上に保持する**」にしておく。
  ファイル オンデマンドのままだと、PC の Obsidian 側でファイルが見えなくなることがある（この画面の問題ではない）。
- 同じノートを PC とスマホで**同時に**開いて書くと、後から保存した方に競合の確認が出る。

## ファイル

```
notes/
  index.html       画面の骨組み
  style.css        見た目（端末の明暗に合わせる）
  config.js        クライアント ID（任意）
  js/auth.js       サインイン（認可コード + PKCE、秘密鍵なし）
  js/graph.js      OneDrive の読み書き（eTag による競合検出）
  js/vault.js      保管庫の目録と [[リンク]] の探し方（Obsidian と同じ規則）
  js/render.js     Markdown の表示（Obsidian の書き方を拾う）
  js/reader.js     文字の見え方・目次・マーカー
  js/db.js         端末の控え（IndexedDB）
  js/lock.js       パスワードと鍵（暗号化・自動ロック）
  js/store.js      端末の控えを暗号化して出し入れする
  js/app.js        画面の動き
  vendor/          marked（MIT）・DOMPurify（Apache-2.0 / MPL-2.0）・editor.js（CodeMirror 6、MIT）
  sw.js            オフライン用キャッシュ
```

`vendor/editor.js` は `tools/notes-editor/` で `npm install && npm run build` して作る（手で直さない）。

画面を更新したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が残る。
