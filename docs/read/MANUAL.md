# ぽちゃ文庫

読むための画面と、読んだ記録を1つにした自分用の読書アプリ。
端末の中だけで動く。本もメモもどこにも送らない。

**URL** → https://aji-daze.github.io/kb-cso/read/

---

## 1. 入れる

1. **Android** … Chrome で開く → メニュー ⋮ →「アプリをインストール」
2. **iPhone / iPad** … **Safari で**開く → 共有（□に↑）→「ホーム画面に追加」
   - iOS は Safari 限定。Chrome では出ない
3. 追加されたアイコンから起動すると、アドレスバーのない全画面になる

一度開けば、以後は電波がなくても起動する。

> [!warning] iOS はホーム画面に追加した状態で使う
> Safari のタブのままだと、保存の扱いが不安定になる。

### 最初にやること

- 設定（右上の ⚙）→ **保存を固定する** を押す
  → 端末の空きが減っても、本が勝手に消されにくくなる
- Android なら 設定 → **明朝** → 取り込む（[[#明朝がない端末]]）

### 更新

直すたびに自動で新しくなる。反映されないときはアプリを開き直す。

> [!note] アイコンと名前はすぐ変わらない
> ホーム画面に追加した時点で端末側に焼き付くため。いったん外して追加し直すと変わる。

---

## 2. 本を入れる

「本を入れる」から4つ。

| 入れ方 | 中身 |
| --- | --- |
| **フォルダを開く** | 本の入ったフォルダごと。**OneDrive の同期フォルダでよい**。一度選ぶと覚える |
| **ファイルを選ぶ** | 1冊ずつ。EPUB・Markdown・テキスト・青空文庫の zip |
| **青空文庫** | 目録から探して落とす |
| **Google ドライブ / OneDrive** | クラウド側を直接たどる（同期フォルダが無い端末向け） |

### 読める形式

- **EPUB**（DRM の無いもの）
- **Markdown** `.md`
- **テキスト** `.txt`
- **青空文庫の zip** — そのまま入れてよい。中の Shift_JIS を開いて、ルビと縦組みで出る

> [!danger] Kindle は開けない
> DRM があり、Web から読む手段が無い。回避策も無い。
> Kindle の本は「棚に登録して、進みを手で書き込む」までしかできない。

---

## 3. フォルダを開く（いちばん楽）

OneDrive は PC では**ただのフォルダ**として端末の中にある。
だからクラウドにつなぐ必要はない。そのフォルダを開けばいい。**認証もアプリ登録も要らない。**

「本を入れる」→「フォルダを開く」→ `OneDrive\書籍` を選ぶ。

- **一度選ぶと覚えている。** 次からは選び直さずに中身を見られる
- **取り込んだ本は、このフォルダにも自動で保存される**（設定 → フォルダ で切れる）
- すでに棚にある本は「✓ 取り込み済み」で、二重に入らない
- PC 側で書き換えた本は「↻ 書き換えられています」で、入れ直せる

### 見に行かないフォルダ

ポメラ（pomera-tab）と同じ扱いにしてある。

`Personal Vault` / `Microsoft Copilot Chat ファイル` / `アプリ` / `Desktop` / `画像` / `動画` / `music`
と、先頭が `.` のもの。

### 端末をまたいで同じ本を読む

```
PC で取り込む
   ↓ OneDrive\書籍 にも保存される
   ↓ OneDrive が同期
別の端末で「フォルダを開く」→「まだの ◯件を取り込む」
```

> [!important] 同じになるのは本だけ
> **進捗と抜き書きは端末ごとに別のまま。**
> 抜き書きは Markdown で書き出せば移せる。進捗は移せない。

### 使える端末が限られる

| 端末 | |
| --- | --- |
| PC の Chrome / Edge | 覚えられる・書き込める |
| Android の Chrome | 同上 |
| **iPhone / iPad** | **使えない。** その都度フォルダを選ぶ形になる |
| PC の Firefox / Safari | 同上 |

### 書き込みの許可

フォルダに保存するには書き込みの許可が要る。選ぶときに一緒に聞かれる。
すでに読み取りだけで許可してある場合は、**設定 → フォルダ →「書き込みを許可する」**。

## 4. 青空文庫

**目録だけ先に入れて、読みたいものだけをその都度落とす。**

### なぜ二段階なのか

青空文庫のサーバーは、ブラウザで動くアプリからの読み取りを許可していない（CORS）。
そこで**目録は GitHub Actions が取ってきて、自分のサイトに置いている**。
アプリは自分のサイトから読むだけなので、この壁を越えられる。

### 手順

1. 「本を入れる」→「青空文庫」→ **目録を入れる**（一度だけ・約 700 KB）
2. 作者名や作品名で検索（**通信なしで動く**）
3. 読みたい作品をタップ → **落とす**（ブラウザがファイルを落とす）
4. 「本を入れる」→ **ファイルを選ぶ** → 落ちてきた zip を選ぶ

zip のまま入れてよい。中身を開いて、次を落としてから本文にする。

- 冒頭の見出し（題名・読み・著者・訳者）→ 題名と著者に振り分ける
- `-----` で挟まれた「テキスト中に現れる記号について」の凡例
- 末尾の「底本：」以下の奥付
- 入力者注 `［＃…］`

ルビ `｜漢字《かんじ》` はそのまま縦組みで出る。

### 目録について

- **18,561 作品**（著作権の切れたもの）
- 入っているのは作品名・読み・著者・ダウンロード先の URL だけ。**本文は入っていない**
- 月1回、自動で更新される

> [!note] 手で更新したいとき
> GitHub → Actions → **aozora-index** → Run workflow

## 5. 読む

- **左右をタップしてページを送る**
  - 縦組みでは**左が先へ進む**（右から左へ読むため）
- **中央をタップ** → 上に目次、下に設定
  - 出ている間は、どこを触っても片づけるだけ。ページは送らない
- 本文を**長押しして選ぶ** → そのまま抜き書きにできる

### 残りは「分」で出る

ページ数ではなく分で出す。ページを送った間隔から**あなたの速さを実測**している。

- 10ページほど読むと、仮の値から実測に切り替わる
- 飛ばし読み（4秒未満）や、置きっぱなし（3分超）のページは捨てている
- 人の速さの範囲（80〜2500字/分）から外れた値も捨てる

いまの速さは 記録 → **読む速さ** で見られる。

## 6. 見た目

中央をタップ → 下のシート。**雰囲気**を選ぶと下の値がまとめて動く。動いたあとで個別に触れる。

### 雰囲気

| | 組み方・書体 | 紙 | 効くもの |
| --- | --- | --- | --- |
| **和・縦** | 縦組み／明朝／行間ゆったり | 生成り | 青空文庫の小説、日本語の EPUB |
| **覚え書き** | 横組み／ゴシック／行間つめ | 白磁 | Markdown、実用書、自分のノート |
| **洋・古典** | 横組み／欧文セリフ／ハイフネーション／頭文字を大きく | 古紙 | 洋書 |
| **研究** | 横組み／小さめ／余白を削る | 白磁 | 通読ではなく参照 |
| **夜** | 組み方はそのまま／紙だけ墨に | 墨 | 暗所 |

**雰囲気は本ごとに覚える。** 小説を縦で、ノートを横で、が両立する。

### 個別に触れる値

| 項目 | 範囲 |
| --- | --- |
| 組み方 | 縦 / 横 |
| 書体 | 明朝 / ゴシック / 丸ゴシック / 欧文セリフ |
| 文字の大きさ | 12〜30px |
| 行間 | 130〜280% |
| 字送り | 0〜0.16em |
| 版面の余白 | 6〜72px |
| **紙の色** | 白磁 / 生成り / 古紙 / セピア / 薄氷 / 霧 / 墨 |
| **紙の目** | 0〜100 |
| 目の細かさ | 0〜100 |
| 綴じ側の陰り | 0〜100 |
| インクの濃さ | 55〜100 |
| ページ送り | なし / 薄く |

**文字の大きさや行間を変えても、読んでいた位置はそのまま。**

> [!tip] 紙の目は強くしても読みやすくならない
> 文字と地の差が縮むだけ。効くのは、効いていると気づかない強さまで。
> 暗い紙にのせると画面が真っ黒でなくなるので、有機 EL の省電力が効かなくなる。

### アプリ側の配色

棚・抜き書き・記録の配色は右上の ⚙ から別に選ぶ。

- **テーマ** … 墨 / 霧 / 灰 / 藍鉄 / 生成り / 白磁 / **しろくま**（白っぽいグレー）
- **アクセント** … 琥珀 / 錆 / 苔 / 藤 / 鴇 / 浅葱 / 藍 / 芥子 / 桑 / **水色** / モノクロ
- **フォント** … システム標準 / ゴシック / 明朝 / 丸ゴシック

### 明朝がない端末

**iOS にはヒラギノ明朝があるが、Android には明朝が無い。**
標準はゴシックだけなので、「明朝」を選んでも黙ってゴシックで出る。

設定 → **明朝** → 取り込む（約 3.8 MB・一度だけ）。

- 書体は Noto Serif JP。あなたの端末が Google Fonts から直接落とす
- 125 個の範囲に分かれていて、**必要な字の分だけ読み込む**。重くならない
- 落としたあとはオフラインでも明朝で読める
- 端末に明朝がある場合は、そちらが優先される

## 7. 抜き書き

引用と、そのとき書いた自分の反応を対で持つ。**あとで効くのは反応のほう。**

- 本文を長押しして選ぶ → 「抜き書きにする」
- 上に「1年前の今日」が1枚だけ出る（日替わり）
- タグで絞り込める
- **Markdown で書き出せる** → 引用・出典・反応・タグの4点セット。そのまま文献ノートに積める

## 8. 読了

星はつけない。代わりに「**一番残った一文**」を抜き書きから1つだけ選ぶ。

> [!note] なぜ星をやめたか
> 他人に見せないなら ★4 と ★5 の区別に意味がない。
> 付けるのが面倒になって、記録そのものが止まる。

## 9. 記録

いつ・何分読んだかを残す。冊数ではなく時間で見る。
**連続日数やバッジは出さない**（途切れた日に開かなくなるため）。

DESK が動いていれば、読書の分数はそちらの集中セッションにも流れる。

---

## 10. 気をつけること

> [!danger] 消えるとき
> ブラウザの「サイトデータを削除」を実行すると、**本も抜き書きも全部消える**。

- **容量** … 本は端末のブラウザ保存領域に入る。設定で使用量が見られる
- **バックアップ** … 元のファイルは残しておく。アプリからは書き出せない
- **同期しない** … 進捗と抜き書きは端末ごとに別。本だけはフォルダ経由で揃う

---

## 11. 困ったとき

| 症状 | |
| --- | --- |
| 新しい版にならない | アプリを開き直す |
| アイコン・名前が古い | ホーム画面から外して追加し直す |
| 「明朝」にしてもゴシックのまま | Android。設定 → 明朝 → 取り込む |
| フォルダが選べない | iOS か Firefox。[[#使える端末が限られる]] |
| フォルダに保存されない | 設定 → フォルダ →「書き込みを許可する」 |
| 目録が取れない | 出たエラー文をそのまま控える。取得元と理由が書いてある |
| 残り時間がおかしい | 記録 → 読む速さ を見る。実測が溜まるまでは仮の値 |

---

## 12. まだできないこと

- **PDF** … pdf.js が要る。固定レイアウトは文字サイズを変えられないので、入れるならタブレット専用
- **端末をまたいだ進捗の同期** … 本だけはフォルダ経由で揃う。進捗は別の仕組みが要る
- **青空文庫のワンタップ取り込み** … CORS のため「落とす → 選ぶ」の2手
- **ConTodo 連携**
- **EPUB の挿絵** … 本文だけ取り出している。表紙は書影に使う

## 付録：中身

ビルド不要の素の ES モジュール。外部ライブラリなし。

```
docs/read/
├── index.html      画面の骨組み
├── style.css       テーマ token と読書画面
├── manifest.json   PWA の設定
├── sw.js           オフライン用キャッシュ
├── data/           青空文庫の目録（Actions が作る）
└── js/
    ├── app.js      画面制御・棚・取り込み・設定
    ├── db.js       IndexedDB
    ├── zip.js      zip の読み取り（DecompressionStream）
    ├── md.js       Markdown・テキスト・青空文庫の解析
    ├── epub.js     EPUB の展開
    ├── aozora.js   青空文庫の目録
    ├── folder.js   端末のフォルダ（File System Access API）
    ├── drive.js    Google ドライブ
    ├── onedrive.js OneDrive（Microsoft Graph・PKCE）
    ├── paper.js    雰囲気・紙・組み方
    ├── pager.js    ページ分割
    ├── font.js     明朝の取り込み
    ├── notes.js    抜き書き
    └── stats.js    読む速さ・読書セッション
```

画面を直したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が残る。
