# ぽちゃ文庫

読むための画面と、読んだ記録を1つにした自分用の読書アプリ。
端末の中だけで動く。本もメモもどこにも送らない。例外は**辞書**だけで、「辞書」を押したときに、選んだ語（語だけ）をウィクショナリー／ウィキペディアに送って引く。

**URL** → https://aji-daze.github.io/kb-cso/read/

---

## 1. 入れる

1. **Android** … Chrome で開く → メニュー ⋮ →「アプリをインストール」
2. **iPhone / iPad** … **Safari で**開く → 共有（□に↑）→「ホーム画面に追加」
   - iOS は Safari 限定。Chrome では出ない
3. 追加されたアイコンから起動すると、アドレスバーのない全画面になる

一度開けば、以後は電波がなくても起動する。

> [!warning] iOS はホーム画面に追加した状態で使う
> Safari のタブのままだと、保存の扱いが不安定になる。

### 最初にやること

- 設定（右上の ⚙）→ **保存を固定する** を押す
  → 端末の空きが減っても、本が勝手に消されにくくなる
- Android なら 設定 → **明朝** → 取り込む（[[#明朝がない端末]]）

### 更新

直すたびに自動で新しくなる。反映されないときはアプリを開き直す。

> [!note] アイコンと名前はすぐ変わらない
> ホーム画面に追加した時点で端末側に焼き付くため。いったん外して追加し直すと変わる。

## 2. 本を入れる

「本を入れる」から4つ。

| 入れ方 | 中身 |
| --- | --- |
| **フォルダを開く** | 本の入ったフォルダごと。**OneDrive の同期フォルダでよい**。一度選ぶと覚える |
| **ファイルを選ぶ** | 1冊ずつ |
| **青空文庫** | 目録から探して落とす |
| **その他** | クラウド（Google ドライブ / OneDrive）・紙の本・見本 |

### 読める形式

- **EPUB**（DRM の無いもの）
- **Markdown** `.md` — 5万字より短いものは「文書」に入る（下の「7. 文書」）。長いものは本として棚に入る
- **テキスト** `.txt`
- **青空文庫** — zip のままでも、展開した `.txt` でもよい

> [!tip] 文字コードは気にしなくていい
> 青空文庫のテキストは Shift_JIS だが、中身を見て自動で判別する。
> 凡例と奥付も落として、ルビと縦組みで出す。

> [!danger] Kindle は開けない
> DRM があり、Web から読む手段が無い。回避策も無い。
> Kindle の本は「棚に登録して、進みを手で書き込む」までしかできない。

> [!tip] Android は「共有」からも入れられる
> ホーム画面に追加してあれば、他のアプリの共有メニューに「ぽちゃ文庫」が出る。
> そこから EPUB・Markdown・テキストを共有すると、そのまま棚に入る。
> 追加した直後は端末側の更新に時間がかかり、共有メニューに出るまで少し待つことがある。

## 3. フォルダを開く（いちばん楽）

OneDrive は PC では**ただのフォルダ**として端末の中にある。
だからクラウドにつなぐ必要はない。そのフォルダを開けばいい。**認証もアプリ登録も要らない。**

「本を入れる」→「フォルダを開く」→ `OneDrive\書籍` を選ぶ。

- **一度選ぶと覚えている。** 次からは選び直さずに中身を見られる
- **取り込んだ本は、このフォルダにも自動で保存される**（設定 → フォルダ で切れる）
- すでに棚にある本は「✓ 取り込み済み」で、二重に入らない
- PC 側で書き換えた本は「↻ 書き換えられています」で、入れ直せる
- **開くときに自動で新しい版になる。** フォルダや OneDrive から入れた本・文書は、開くたびに元のファイルが書き換わっていないかを見て、
  書き換わっていればその場で取り込み直してから開く（「新しい版に更新しました」と出る）。入れ直しの操作は要らない
- 同じ名前のファイルをもう一度入れたときも、**別の本は増えずに中身だけが新しくなる**。読んだ位置・印・抜き書き・ページ設定・状態はそのまま

> [!note] 自動で見に行けないとき
> 電波が悪い（3秒で返事が無い）、OneDrive のサインインが切れている、フォルダの読み取り許可がその場で無い、のどれかなら、
> 手元の版でそのまま開く。フォルダの許可は、Chrome でフォルダを開き直して「毎回許可」にしておくと切れない。
> Google ドライブから入れた本は自動では見ない（入れ直しで更新する）。

### 見に行かないフォルダ

ポメラ（pomera-tab）と同じ扱いにしてある。

`Personal Vault` / `Microsoft Copilot Chat ファイル` / `アプリ` / `Desktop` / `画像` / `動画` / `music`
と、先頭が `.` のもの。

### 端末をまたいで同じ本を読む

```
PC で取り込む
   ↓ OneDrive\書籍 にも保存される
   ↓ OneDrive が同期
別の端末で「フォルダを開く」→「まだの ◯件を取り込む」
```

> [!important] 同じになるのは本だけ
> **進捗と抜き書きは端末ごとに別のまま。**
> 抜き書きは Markdown で書き出せば移せる。進捗は移せない。

### 使える端末が限られる

| 端末 | |
| --- | --- |
| PC の Chrome / Edge | 覚えられる・書き込める |
| Android の Chrome | 同上 |
| **iPhone / iPad** | **使えない。** その都度フォルダを選ぶ形になる |
| PC の Firefox / Safari | 同上 |

### 書き込みの許可

フォルダに保存するには書き込みの許可が要る。選ぶときに一緒に聞かれる。
すでに読み取りだけで許可してある場合は、**設定 → フォルダ →「書き込みを許可する」**。

## 4. 青空文庫

**目録だけ先に入れて、読みたいものだけをその都度落とす。**

### なぜ二段階なのか

青空文庫のサーバーは、ブラウザで動くアプリからの読み取りを許可していない（CORS）。
そこで**目録は GitHub Actions が取ってきて、自分のサイトに置いている**。
アプリは自分のサイトから読むだけなので、この壁を越えられる。

### 手順

1. 「本を入れる」→「青空文庫」→ **目録を入れる**（一度だけ・約 700 KB）
2. 作者名や作品名で検索（**通信なしで動く**）
3. 読みたい作品をタップ → **落とす**（ブラウザがファイルを落とす）
4. 「本を入れる」→ **ファイルを選ぶ** → 落ちてきたファイルを選ぶ

### 作家ごとにまとめて落とす

作者名で検索すると、上に **作家の行**（`有島武郎　52件`）が出る。
タップすると全作品の一覧になり、**「52件まとめて落とす」**でまとめて落とせる。

落ちきったら「本を入れる」→「ファイルを選ぶ」で、**複数まとめて選んで**取り込む。

> [!warning] ブラウザが一度だけ確認してくる
> 「複数のファイルをダウンロードしますか」と聞かれるので許可する。
> 1件あたり 0.3 秒ほどかけて流すので、52件なら 16 秒ほどかかる。

> [!note] なぜ一括でもアプリの中に入らないのか
> 青空文庫のサーバーはアプリからの読み取りを許可していない（CORS）。
> ブラウザ自身に落としてもらうしかなく、そのぶん取り込みが1手増える。

**zip のままでも、展開した `.txt` でもよい。** 次を落としてから本文にする。

- 冒頭の見出し（題名・読み・著者・訳者）→ 題名と著者に振り分ける
- `-----` で挟まれた「テキスト中に現れる記号について」の凡例
- 末尾の「底本：」以下の奥付
- 入力者注 `［＃…］`

ルビ `｜漢字《かんじ》` はそのまま縦組みで出る。

### 目録について

- **18,561 作品**（著作権の切れたもの）
- 入っているのは作品名・読み・著者・ダウンロード先の URL だけ。**本文は入っていない**
- 月1回、自動で更新される

> [!note] 手で更新したいとき
> GitHub → Actions → **aozora-index** → Run workflow

## 5. ホーム画面

下タブのいちばん左、**ホーム**。起動すると最初に出る。上から順に3つ。

### 今日の一節

文学の一節を1件。日付で決まるので、同じ日に何度開いても同じものが出る。
**押すと、その作品を開く。**棚に無ければ青空文庫の検索が作品名入りで開くので、
そのまま落とせる。

入っているのは38件。すべて**青空文庫にある、著作権保護期間の満了した作品**から引いた。
漱石・鴎外・芥川・太宰・賢治・中島敦・梶井・安吾・一葉・子規・啄木・三木清ほか。

> [!note] 文字は底本と照合してある
> 記憶で書くと字が違う（「病牀六尺」は本文では「病床六尺」、
> 「木曽路」は底本では「木曾路」）。全件、青空文庫の底本テキストと
> 1文字ずつ突き合わせて写した。

足したいときは `js/quotes.js` の配列に同じ形で書き足す。
`work` を青空文庫の作品名と揃えておくと、押したときに探しに行ける。

### つづきの本

最後に開いた本。なければ「読んでいる」本の先頭。
表紙・著者・進み具合を出す。押すとそのまま本文に入る。
紙・Kindle として登録した本のときは、代わりに進みを書き込む画面が出る。

### 本棚（読みかけ）

**「読んでいる」本を、背表紙で二段だけ**並べる。蔵書を全部出す場所ではない。
背表紙を押すと、その本の操作（開く・読んでいる／読んだに入れる・消す）が出る。

- **読みかけが先**。一度でも開いた本を、最後に開いた順で前に出す
- **幅**は本の長さ。長い本ほど厚い
- **色**は題名から決まる。同じ本はいつも同じ色
- 二段に入りきらないぶんは切る。見出しの「棚へ ▸」で、棚を「読んでいる」に絞って開く

いちばん下に、読んでいる冊数・今月入った冊数・今月出た冊数。

> [!tip] しろくまは棚の上にいる
> 本を読んでいて、ときどきまばたきをして、ページをめくる。約2.3秒でひと回り。
> 意味はない。触っても何も起きない。
>
> 端末の設定で「視差効果を減らす／アニメーションを減らす」を入れていると、
> 動かない絵に切り替わる。

> [!tip] しおりが垂れている本は読みかけ
> 進みが付いている（一度でも開いた）本の背表紙には、上の縁からアクセント色の
> 小さなしおりが垂れる。見出しの「読みかけ N冊」と同じ本を指す。

## 6. 棚

下タブの2つめ。**表紙を並べて出す。**蔵書を全部見るのはここ。

- 上の3つは**絞り込み** … 本棚 / 読んでいる / 読んだ（右の数字は冊数）
  - **本棚** … 入れた本すべて。読んでいる本も読んだ本も含む
  - **読んでいる** … 開いた本（読みかけ）だけ
  - **読んだ** … 読み終えた本だけ
- 取り込んだ本は「本棚」に入るだけ。**開いた時点で「読んでいる」に入る**。紙・Kindle の登録は最初から「読んでいる」
- 「本棚」で全部を並べたとき、読んでいる本の表紙にはアクセント色のしおり紐が垂れる
- 表紙を押すと、その本の操作（開く・読んでいる／読んだに入れる・外す・消す）が出る。**外す**は本棚に戻すだけで、本は消えない
- 表紙の下は進みの線と、読み終わるまでのおおよその分
- 読んだ本は表紙が薄くなり、右上に ✓ がつく
- 左上の 🔍 で題名・著者から探せる

### 整理する

絞り込みの下に3つのボタンが並んでいる。作家の絞り込みは、上の3つを切り替えても残る。

| ボタン | すること |
| --- | --- |
| **作家 すべて ▾** | 作家で絞る。冊数の多い順に出る。上の欄で作家名を打つと絞れる |
| **並べ替え ▾** | 追加が新しい順 / 題名の順 / 作家でまとめる / 進みが多い順 / 長い順 |
| **選ぶ** | まとめて動かす。表紙を押すと ✓ がつく |

「選ぶ」を押すと下に帯が出る。**すべて**で全部に ✓、もう一度押すと解除。
そこから**まとめて「読んでいる」「読んだ」に入れる／外す**か、**まとめて消す**。

> [!note] 「作家でまとめる」は五十音順ではない
> 漢字の名前から読みを取れないので、五十音に並べられない。
> 代わりに**冊数の多い作家から**まとまりを作る。同じ作家の本は必ず隣り合う。

> [!note] 前の版から使っている場合
> 前の版では、取り込んだだけの本も「読んでいる」に入っていた。一度も開いていない本は、
> 更新後の最初の起動で「読んでいる」から外れる（本棚には残る）。「積んでいる」だった本も本棚に入る。

> [!note] 選んでいる最中に絞り込むと
> 作家の絞り込みや並べ替えを変えると、そのとき画面から見えなくなった本は選択から外れる。
> 「すべて」・移す・消す、はいつも今見えている本だけが対象になる。

> [!note] 表紙のつくり
> どの本も昔の文庫本のような同じ装い（紙の地・細い二重の枠・上の色帯・題名を書いた題簽）で出す。
> 紙と帯の色は6通りあり、題名で決まる。同じ本はいつも同じ色。横文字の題名は横に組む。

### 見ていた画面は残る

下に引っ張って更新しても、アプリを閉じて開き直しても、
**最後に見ていたタブと段に戻る。**更新のたびに「ホーム」へ飛ばされない。

> [!warning] 読書画面は戻らない
> 更新すると本文は閉じる。つづきは「ホーム」タブから入り直す。
> 止まった位置は残っているので、読み直しにはならない。

## 7. 文書

下タブの3つめ。**本ではない Markdown**（覚え書き・調べもの・分析のメモなど）の置き場。
表紙は出さず、題名と書き出しの一覧にする。開くと**横書きの1枚の紙**になり、ページはめくらずにスクロールで読む。

- Markdown（`.md`）は、**5万字より短ければ文書**に入る。長いもの（小説など）は本として棚に入る
- 文書の「⋯」→「本として棚に移す」で本にできる。逆に、棚の Markdown の本は「文書に移す」で文書にできる
- 上の欄に打つと、題名・フォルダ・書き出しで絞れる
- 並べ替え … 最近開いた順 / 入れた順 / 名前の順（`6_…` のような番号つきの名前は番号の順）/ フォルダごと
- 読んでいた位置は覚える。一覧に「45%まで」のように出る
- 文書は「読んでいる」「記録」に数えない（読書の時間にも入れない）

### 読む画面

紙の文書のように読む。上に**題名と日付の柱**（日付はプロパティの `date` / `created`、なければ入れた日）、
本文は明朝（欧文は Times 系）の**両端揃え**。

読み方は2つ。**Aa** で切り替える（選んでいなければ、タブレットなど幅のある画面は「めくる」、スマホは「スクロール」）。

- **めくる** … ページで読む。右の3分の1を押すか左へ払うと次、左の3分の1か右へ払うと前。真ん中を押すと上の帯が出る。
  下にページ番号。**幅があれば2段組み**。キーボードは ← → ・Space・PageUp/PageDown
- **スクロール** … 1枚の長い紙。幅のある画面では、机の上に紙を1枚置いた形になる

| ボタン | すること |
| --- | --- |
| **‹** | 一覧に戻る。Android の「戻る」でも同じ |
| **目次** | 見出しの一覧と、引いた印の一覧。押すとそこへ |
| **Aa** | 読み方・紙（紙・セピア・黒・アプリと同じ）・文字の大きさ・書体（明朝・ゴシック）。端末ごとに覚える |

### 印を引く

文字を選ぶと下に帯が出る。

- **黄・桃** … 蛍光ペン
- **青の線** … ペンで引いた下線
- **抜き書き** … 抜き書きに入れる（どの見出しの下の文かも残る）

引いた印を押すと、色を変える・**メモ**を書く・抜き書きにする・消す。メモのある印には青い ✎ が付く。
印は「その文字列と直前の数十字」で覚えるので、文字の大きさや読み方を変えても同じ所に引き直される。
元の Markdown を書き換えてその文がなくなると、その印は出なくなる。

> [!note] 手書きはできない
> ペンで余白に字や線を書く機能はない。代わりに印のメモを使う。

### 出せる書き方

見出し・太字・斜体・`コード`・コードの塊・箇条書き（入れ子も）・番号・表・引用・区切り線・リンク。
Obsidian の書き方も拾う：`[[ノート]]`（同じ名前の文書があれば開く）・`==強調==`・`#タグ`・`%%コメント%%`（出さない）・
`> [!note]` のコールアウト・`- [ ]` チェックボックス（見るだけ。押せない）・先頭の `---` プロパティ（たたんで出す）。
段落の中の改行はそのまま改行になる（Obsidian と同じ）。

> [!note] 出せないもの
> 保管庫の中の画像（`![[画像.png]]`）は、このアプリに画像が無いので名前だけ出す。ネット上の画像（`https://…`）は出る。
> 書き換えはできない。書くのはノート（Obsidian）側で。

> [!note] 前の版から使っている場合
> 前の版では Markdown も本として棚に入っていた。更新後の最初の起動で、5万字より短い Markdown の本を一度だけ「文書」に移す。
> 見本（使い方の文章）は動かさない。

## 8. 読む

- **左右をタップしてページを送る**
  - 縦組みでは**左が先へ進む**（右から左へ読むため）
- **左右に指でずらす** … ずらした分だけ隣のページが見える。
  指を離したところで、送るか戻るかが決まる
- **本文を長押しすると文字を選べる** … 下に「抜き書きにする」が出る。
  選んだ状態でどこかを触ると選択が消えるだけで、ページは送らない
- **端末の「戻る」** … 開いているものを1枚ずつ閉じる。
  シート → 読書画面 → アプリの順。各シートの右上 ✕ でも閉じる

### 指でずらす

| | 縦組み | 横組み |
| --- | --- | --- |
| 右へ払う | 先へ進む | 前へ戻る |
| 左へ払う | 前へ戻る | 先へ進む |

- 版面の**2割ほど**ずらすか、**速く払う**と送られる。それ以下なら戻る
- ずらしている間、継ぎ目に紙の端らしい影が出る
- 設定 → **ページ送り** → 「めくる」のときだけ働く（既定）

> [!note] 紙がめくれ上がる表現は入れていない
> 本文は1本の流れとして組んでいて、ページはその窓として切り出している。
> 角が3Dでめくれる表現にするには、文字を毎フレーム描き直すことになり、
> 長い本では確実に重くなる。ずらして隣が見える形までにしてある。
- **中央をタップ** → 上に目次、下に設定
  - 出ている間は、どこを触っても片づけるだけ。ページは送らない
- 本文を**長押しして選ぶ** → そのまま抜き書きにできる

### 残りは「分」で出る

ページ数ではなく分で出す。ページを送った間隔から**あなたの速さを実測**している。

- 10ページほど読むと、仮の値から実測に切り替わる
- 飛ばし読み（4秒未満）や、置きっぱなし（3分超）のページは捨てている
- 人の速さの範囲（80〜2500字/分）から外れた値も捨てる

いまの速さは 記録 → **読む速さ** で見られる。

---

## 9. 見た目

中央をタップ → 下のシート。**雰囲気**を選ぶと下の値がまとめて動く。動いたあとで個別に触れる。

### ページ設定の引き継ぎ

設定は**本ごとに覚える**。触った瞬間にその本の設定として残り、保存ボタンは無い。

| 開いた本 | 使う設定 | 画面に出るもの |
| --- | --- | --- |
| 前に開いた本 | その本で最後に使った設定 | 何も出ない |
| 初めての本 | 直前に読んでいた本の設定（前回の設定） | 上に一行「前回の設定（「◯◯」で使用）で開きました」＋［他の本の設定］［このままでいい］。ページを送ると消える |
| 初めて・履歴なし | 形式ごとの既定（和書は和・縦、洋書は洋・古典、Markdown は覚え書き） | 同上。写せる本が無ければ［他の本の設定］は出ない |

- **［他の本の設定］** … 設定を持っている本を、同じ形式（和書・洋書・Markdown）を先に、その中は最近開いた順に並べる。押すとこの本に写す。読書中もシートの「引き継ぎ」から出せる
- **写すのは複製。** 写したあとで元の本を変えても、こちらは動かない
- **形式で決まる所は写さない。** Markdown と洋書は横組み固定（縦の本から写しても横のまま）。洋書の組み方（ハイフネーションなど）は本の言語で決まる
- 前の版から読んでいる本は、前の見た目のまま開く（一行は出ない）

### 辞書

読んでいて文字を選ぶと、帯に**辞書**が出る（本の読書画面・文書の両方）。

- 日本語はウィクショナリー、無ければウィキペディアの要約。英語は英語版ウィクショナリー
- **ルビの付いた語を選ぶと、本文のルビを読みとして出す**（いちばん確か）
- 「邂逅した」のように送り仮名ごと選んでも、語幹（「邂逅」）で引き直す
- 下に Weblio・Google（英語は Cambridge）へのリンク。引けなかったときはここから
- 電波が無いときは引けない。語をネットに送るのは「辞書」を押したときだけ

### 雰囲気

| | 組み方・書体 | 紙 | 効くもの |
| --- | --- | --- | --- |
| **和・縦** | 縦組み／明朝／行間ゆったり | 生成り | 青空文庫の小説、日本語の EPUB |
| **覚え書き** | 横組み／ゴシック／行間つめ | 白磁 | Markdown、実用書、自分のノート |
| **洋・古典** | 横組み／欧文セリフ／ハイフネーション／頭文字を大きく | 古紙 | 洋書 |
| **研究** | 横組み／小さめ／余白を削る | 白磁 | 通読ではなく参照 |
| **夜** | 組み方はそのまま／紙だけ墨に | 墨 | 暗所 |

**雰囲気は本ごとに覚える。** 小説を縦で、ノートを横で、が両立する。

### 個別に触れる値

| 項目 | 範囲 |
| --- | --- |
| 組み方 | 縦 / 横 |
| 書体 | 明朝 / ゴシック / 丸ゴシック / 欧文セリフ |
| 文字の大きさ | 12〜30px |
| 行間 | 130〜280% |
| 字送り | 0〜0.16em |
| 版面の余白 | 6〜72px |
| **紙の色** | 白磁 / 生成り / 古紙 / セピア / 薄氷 / 霧 / 墨 |
| **紙の目** | 0〜100 |
| 目の細かさ | 0〜100 |
| 綴じ側の陰り | 0〜100 |
| インクの濃さ | 55〜100 |
| ページ送り | なし / 薄く / めくる |

**文字の大きさや行間を変えても、読んでいた位置はそのまま。**

> [!tip] 紙の目は強くしても読みやすくならない
> 文字と地の差が縮むだけ。効くのは、効いていると気づかない強さまで。
> 暗い紙にのせると画面が真っ黒でなくなるので、有機 EL の省電力が効かなくなる。

### アプリ側の配色

棚・抜き書き・記録の配色は右上の ⚙ から別に選ぶ。

- **テーマ** … 墨 / 霧 / 灰 / 藍鉄 / 生成り / 白磁 / **しろくま**（白っぽいグレー）
- **アクセント** … 琥珀 / 錆 / 苔 / 藤 / 鴇 / 浅葱 / 藍 / 芥子 / 桑 / **水色** / モノクロ
- **フォント** … システム標準 / ゴシック / 明朝 / 丸ゴシック

### 明朝がない端末

**iOS にはヒラギノ明朝があるが、Android には明朝が無い。**
標準はゴシックだけなので、「明朝」を選んでも黙ってゴシックで出る。

設定 → **明朝** → 取り込む（約 3.8 MB・一度だけ）。

- 書体は Noto Serif JP。あなたの端末が Google Fonts から直接落とす
- 125 個の範囲に分かれていて、**必要な字の分だけ読み込む**。重くならない
- 落としたあとはオフラインでも明朝で読める
- 端末に明朝がある場合は、そちらが優先される

## 10. 抜き書き

引用と、そのとき書いた自分の反応を対で持つ。**あとで効くのは反応のほう。**

- 本文を長押しして選ぶ → 「抜き書きにする」
- 上に「1年前の今日」が1枚だけ出る（日替わり）
- タグで絞り込める
- **Markdown で書き出せる** → 引用・出典・反応・タグの4点セット。そのまま文献ノートに積める

## 11. 読了

星はつけない。代わりに「**一番残った一文**」を抜き書きから1つだけ選ぶ。

> [!note] なぜ星をやめたか
> 他人に見せないなら ★4 と ★5 の区別に意味がない。
> 付けるのが面倒になって、記録そのものが止まる。

## 12. 記録

いつ・何分読んだかを残す。冊数ではなく時間で見る。
**連続日数やバッジは出さない**（途切れた日に開かなくなるため）。

DESK が動いていれば、読書の分数はそちらの集中セッションにも流れる。

## 13. 気をつけること

> [!danger] 消えるとき
> ブラウザの「サイトデータを削除」を実行すると、**本も抜き書きも全部消える**。

- **容量** … 本は端末のブラウザ保存領域に入る。設定で使用量が見られる
- **バックアップ** … 元のファイルは残しておく。アプリからは書き出せない
- **同期しない** … 進捗と抜き書きは端末ごとに別。本だけはフォルダ経由で揃う

## 14. 困ったとき

| 症状 | |
| --- | --- |
| 新しい版にならない | アプリを開き直す |
| アイコン・名前が古い | ホーム画面から外して追加し直す |
| 「明朝」にしてもゴシックのまま | Android。設定 → 明朝 → 取り込む |
| フォルダが選べない | iOS か Firefox。[[#使える端末が限られる]] |
| フォルダに保存されない | 設定 → フォルダ →「書き込みを許可する」 |
| 目録が取れない | 出たエラー文をそのまま控える。取得元と理由が書いてある |
| 本文が文字化けする | 直したはず。出たらファイル名を控えて知らせる |
| 残り時間がおかしい | 記録 → 読む速さ を見る。実測が溜まるまでは仮の値 |

## 15. まだできないこと

- **PDF** … pdf.js が要る。固定レイアウトは文字サイズを変えられないので、入れるならタブレット専用
- **端末をまたいだ進捗の同期** … 本だけはフォルダ経由で揃う。進捗は別の仕組みが要る
- **青空文庫のワンタップ取り込み** … CORS のため「落とす → 選ぶ」の2手
- **ConTodo 連携**
- **EPUB の挿絵** … 本文だけ取り出している。表紙は書影に使う

## 付録：中身

ビルド不要の素の ES モジュール。外部ライブラリは、文書を描くための marked と DOMPurify だけ（`vendor/` に同梱。ネットからは取らない）。

```
docs/read/
├── index.html      画面の骨組み
├── style.css       テーマ token と読書画面
├── manifest.json   PWA の設定
├── sw.js           オフライン用キャッシュ
├── data/           青空文庫の目録（Actions が作る）
├── vendor/         marked・DOMPurify（ノートのアプリと同じ版を写したもの）
└── js/
    ├── app.js      画面制御・棚・取り込み・設定
    ├── db.js       IndexedDB
    ├── zip.js      zip の読み取り（DecompressionStream）
    ├── md.js       Markdown・テキスト・青空文庫の解析
    ├── mdview.js   文書（本ではない Markdown）を描く。marked・DOMPurify を使う
    ├── epub.js     EPUB の展開
    ├── aozora.js   青空文庫の目録
    ├── folder.js   端末のフォルダ（File System Access API）
    ├── drive.js    Google ドライブ
    ├── onedrive.js OneDrive（Microsoft Graph・PKCE）
    ├── paper.js    雰囲気・紙・組み方
    ├── pager.js    ページ分割
    ├── font.js     明朝の取り込み
    ├── notes.js    抜き書き
    └── stats.js    読む速さ・読書セッション
```

画面を直したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が残る。
