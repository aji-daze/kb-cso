# DESK — タブレット用のミニマリスト作業画面

タブレットをデスクトップのように使うための、1画面完結の作業ダッシュボード。
ブラウザで開き、ホーム画面に追加すると全画面のアプリとして起動する。通信なしでも動く。

公開先: `https://<ユーザー名>.github.io/kb-cso/desk/`

## できること

| 場所 | 内容 |
| --- | --- |
| 左 | 時計 / 就業時間の進捗リング / タスク消化率 / 集中タイマー（作業・休憩の往復と本数記録）/ 残タスク・次の予定・終業まで |
| 中央 | タイムライン。時間ブロックを置くと1日の形が見える。現在時刻は横線。重なった予定は横に割れる |
| 右 | タスク（未完了が上、消すまで持ち越し）とメモ（自動保存） |
| 下 | よく開くページのショートカット（ドック） |

時間ブロックは「この日だけ / 平日 / 毎日 / 毎週この曜日」で繰り返せる。
時間の行を押すとその時刻でブロックを追加できる。

## キーボード

`N` タスク入力 / `B` ブロック追加 / `F` 集中タイマー / `T` 現在時刻へ / `D` ダーク・ライト切替 / `Esc` 閉じる

## 保存について

データはこの端末のブラウザ（localStorage）にだけ入る。サーバーには何も送らない。
つまり端末をまたいだ同期はできず、履歴を消すと失われる。設定（≡）の「書き出し」で
JSON を保存し、別端末で「読み込み」すれば移せる。

## ホーム画面に追加する（iPad）

1. Safari で上記 URL を開く
2. 共有ボタン → 「ホーム画面に追加」
3. 追加されたアイコンから起動すると、Safari の UI なしの全画面になる

なお、iPadOS のロック画面ウィジェットは WidgetKit（ネイティブアプリ）専用で、
Web アプリからは作れない。この画面はその代わりに、ホーム画面から1タップで開く
作業画面として作ってある。

## ファイル

```
desk/
  index.html      画面の骨組み
  style.css       見た目（ダーク/ライト）
  js/store.js     保存と共通関数
  js/clock.js     時計・リング・数字
  js/timeline.js  タイムラインとブロック編集
  js/tasks.js     タスク
  js/timer.js     集中タイマー
  js/links.js     ドック
  js/app.js       設定・キーボード・起動
  sw.js           オフライン用キャッシュ
```

画面を更新したら `sw.js` の `VERSION` を上げる。上げ忘れると古い画面が残る。
